# event-kiosk

イベント会場に持ち込む縦置きタッチモニター(LG 32U889SA)で、展示車両の諸元・装備や中古車在庫を見せる画面。

- 公開ページ: https://makoto-kasagi-bot.github.io/event-kiosk/
- 対象者: イベントに来たお客様(操作する人)、展示を準備する社員

## 仕組み

- `index.html` 1枚に画面・切り替え・データが全部入っている。データはファイル冒頭の `NEW_CARS` / `USED_CARS`。
- `sw.js` が画面とフォントをブラウザに保存するので、一度ネットにつないで開いておけば、会場でネットがなくても動く(モニターのブラウザが対応していれば)。
- 最初に画面に触れると全画面になる(アドレスバーが隠れる)。
- 90秒触られないとホームに戻る。

## 守るルール

- **公開リポジトリ。** 誰でも見られるので、お客様の個人情報・社外秘の価格・仕入れ情報は入れない。現在は見本データのみ。
- 実データを入れるかどうかは、公開してよい情報か確認してから決める。
- `sw.js` の中身を変えたら `CACHE` の名前(`kiosk-v1`)を上げる。上げないと、モニターに古い画面が残る。

## 本体＋USBで使う場合

モニターのメディアプレイヤーは画像を表示できるが、HTMLのボタンは動かない(2026-10-25 確認)。その場合は画面を画像に書き出してフォルダに分けて並べる。
